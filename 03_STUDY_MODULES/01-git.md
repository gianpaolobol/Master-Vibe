# Settimana 1 — Git e GitHub

Obiettivo: distinguere codice scritto, commit, merge, CI e release.

Fonti: https://git-scm.com/book/en/v2 ; https://skills.github.com/ ; https://docs.github.com/en/actions

Esercizio: in un repository sandbox, crea un branch, modifica un file, esamina git diff, esegui commit, apri una PR e verifica CI. Simula un errore e annullalo con git revert. Non usare reset --hard o force push su branch condivisi.

Quiz: un commit implica una build riuscita? Come distingui revert e reset? Come verifichi che una release contenga un commit?

Accettazione: SHA, diff, PR, risultato CI e prova del rollback.
